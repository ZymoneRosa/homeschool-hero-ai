# Homeschool Hero AI Starter Website

This package includes:

- `index.html` - homepage
- `pricing.html` - pricing page
- `styles.css` - styling
- `script.js` - front-end demo behavior
- `ai/prompts.js` - reusable AI prompt templates
- `api/generate-lesson-example.js` - example OpenAI API function
- `database/supabase-schema.sql` - starter Supabase database tables

## How to use

1. Upload the website files to Netlify or Vercel.
2. Create a Supabase project.
3. Paste `database/supabase-schema.sql` into Supabase SQL Editor and run it.
4. Connect the prompt functions to your app backend.
5. Add Stripe later for paid plans.
